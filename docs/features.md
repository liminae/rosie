# features

Rosie combines ongoing Discord-server progression with compact, interactive activities.

### roses and progression

Players earn and spend roses, track balances, tend gardens, collect companions, and complete recurring activities. Rings support a separate set of redemption and reward interactions.

### games and events

The bot offers button-driven scratch cards, minigames, seasonal events, community drops, and cooperative boss encounters. Gameplay is presented through Discord embeds, menus, and interactive controls.

### social play

Members can compare standings, interact through social commands, and participate in shared events. Server configuration governs which experiences are available.

### source boundary

This repository includes only selected command-layer source snapshots. Internal reward schedules, random outcomes, persistence services, and administrative systems remain private.
